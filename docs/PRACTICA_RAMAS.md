# 🧪 Ejercicio Práctico: Cambiar entre Ramas y Subir Código en Git

En esta práctica vas a aprender a:
1. Cambiar de rama en tu terminal.
2. Hacer un cambio en tu código.
3. Guardar el cambio (commit).
4. Subir el cambio a GitHub en la rama correcta (`git push`).

---

## 🎯 PASO A PASO DEL EJERCICIO

### 1️⃣ Paso 1: Cámbiate a tu rama de trabajo `feature/login-usuario`
Escribe en tu terminal:
```bash
git checkout feature/login-usuario
```
*(Verifica que estás en ella ejecutando `git branch`).*

---

### 2️⃣ Paso 2: Edita este archivo o crea una línea nueva abajo
Escribe algo en la sección de notas al final de este archivo (por ejemplo: *"Práctica completada con éxito por [Tu Nombre]"*).

---

### 3️⃣ Paso 3: Prepara y guarda el cambio (Commit)
Ejecuta en tu terminal:
```bash
git add .
git commit -m "docs: completar practica de cambio de ramas"
```

---

### 4️⃣ Paso 4: Sube el cambio a GitHub
Como estás parado en `feature/login-usuario`, ejecuta:
```bash
git push origin feature/login-usuario
```

---

### 5️⃣ Paso 5: Vuelve a la rama `develop`
```bash
git checkout develop
```
