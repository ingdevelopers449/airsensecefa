## ⚡ Comandos Rápidos cotidianos
```bash

git pull origin develop

# 2. Crear tu rama asignada por tarea
git checkout -b feature/tu-nombre-tarea

# 3. Iniciar servidor Laravel
php artisan serve

# 4. Compilar assets
npm run build
```
