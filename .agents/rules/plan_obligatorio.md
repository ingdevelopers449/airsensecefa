# 📋 REGLA OBLIGATORIA: GENERACIÓN DE PLAN DE IMPLEMENTACIÓN PREVIO

## 🚨 REGLA CRÍTICA DE DESARROLLO

1. **GENERACIÓN OBLIGATORIA DE PLAN DE IMPLEMENTACIÓN:** Antes de realizar cualquier edición, creación o eliminación de código, rutas, controladores, migraciones o vistas en el proyecto **AirSense CEFA**, el agente debe **generar primero un Plan de Implementación detallado**.
2. **VERIFICACIÓN Y APROBACIÓN PREVIA:** 
   - El plan debe ser presentado en formato de artefacto (con `RequestFeedback: true`) para que el usuario o líder de proyecto pueda revisar y aprobar los pasos sugeridos antes de ejecutar cualquier cambio en el código fuente.
   - **PROHIBIDO** modificar archivos de código de forma directa sin antes haber recibido la autorización explícita del usuario sobre el plan propuesto.
