# Reglas del Asistente IA (Antigravity Agent)

## 🚫 Restricción Estricta de Git Push

1. **NO SUBIR CAMBIOS A GITHUB (`git push`):**
   - El agente **TIENE PROHIBIDO** ejecutar comandos de envío de código a repositorios remotos como `git push`, `git push origin main`, `git push origin develop`, o similares.
   - El agente **SOLO** puede realizar cambios locales en el código, crear commits locales (`git commit`), crear ramas locales o guiar al usuario.
   - La acción de publicar o subir código a GitHub (`git push`) es **exclusiva responsabilidad del Líder del Proyecto / Usuario**.
